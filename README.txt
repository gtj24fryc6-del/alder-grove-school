IMPORTANT
---------
- This is a prototype, not yet a live website.
- Opening date, registration status, school capacity, email addresses, staff/governor
  details, policy PDFs, term dates, facilities and several statutory details require
  confirmation. Highlighted placeholders are intentionally retained.
- Contact form is a visual prototype only. It does not send or store messages.
  Before launch, connect it to a secure, approved form service and verify the privacy
  wording. Avoid collecting sensitive information about children.
- Privacy notice is a placeholder only and must be completed by the school.
- The map and sample classroom photos load from third-party online services. Check
  image licensing/permissions, privacy/cookie implications and accessibility before launch.
- Review the full content map's Section 11 checklist before publishing.
- Verify school name, registration, contact details, all policies and statutory
  information with the school and relevant advisers.

HOW TO PREVIEW ON AN IPAD
-------------------------
1. Download and extract this ZIP in the iPad Files app.
2. You may be able to preview index.html by tapping it, but local browser behaviour
   can vary. The reliable approach is to upload the files to a hosting service.
3. To use GitHub Pages, create a repository and upload the HTML files and style.css.
   Follow the current GitHub Pages quick-start instructions:
   https://docs.github.com/en/pages/quickstart
4. Enable Pages for the repository and test the temporary published URL.
5. Connect the school's own domain only after confirming where it is registered and
   checking any existing DNS/email records. Do not replace email DNS records blindly.
6. For the contact form, privacy notice, cookie controls and policy downloads, finish
   configuration before public launch.

The site is plain HTML/CSS/JavaScript, so no build tool or laptop is required for
basic publishing. A laptop can make large file-management tasks easier but is not essential.
